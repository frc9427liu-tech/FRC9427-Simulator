📖 新手教學(電腦操作)

9427 FRC 模擬器:不用接機器人,在電腦上跑機器人程式、用搖桿開車、看 3D 場地。
🛑 緊急停止:鍵盤按 空白鍵 或 Enter,機器人立刻停用。跟真的 Driver Station 一樣,養成習慣。

1. 第一次安裝

  1. 裝 WPILib 2026(寫 FRC 程式本來就要裝的那個,有 VS Code 的)。已經能用 VS Code 部署程式到機器人的電腦,就已經裝好了。
    沒裝的話:到 WPILib 下載頁 下載 WPILib_Windows-2026.x.x.iso → 雙擊打開 → 執行 WPILibInstaller.exe → 一路下一步。
  2. 下載模擬器:GitHub 下載頁 → 點 FRC9427-Simulator-Setup-版本.exe 下載。
  3. 雙擊安裝檔。不用管理員權限,幾秒就裝好,桌面會出現「9427 FRC 模擬器」。
⚠️ 如果跳出藍色視窗「Windows 已保護您的電腦」:按「其他資訊」→「仍要執行」。 這是因為我們沒有花錢買程式碼簽章,不是病毒。
💡 第一次打開比較慢(約 10~15 秒,防毒軟體在掃描新程式),之後大約 2 秒。

2. 開啟專案

  1. 雙擊桌面「9427 FRC 模擬器」,會看到起始畫面。
  2. 按「📂 開啟機器人專案資料夾」,選你的機器人程式資料夾。
    要選哪個? 就是你用 VS Code「開啟資料夾」打開的那個,裡面會有 gradlew.bat、build.gradle、src。
    開過的專案會出現在右邊「最近開過的專案」,下次直接點就好。
  3. 等啟動畫面跑完:它會顯示現在在做什麼 ——「編譯你的程式」「程式沒改過,不用重新編譯 ✓」「機器人程式開機中」。 第一次開約 30 秒,之後通常 5~10 秒。
  4. 看到場地畫面就好了。
💡 程式改完想重新測:按畫面上的「📂 換專案」→ 再點同一個專案,就會重新編譯你改過的程式。

  • 下方側面圖、機構燈:手臂角度、飛輪轉速、每個馬達現在在做什麼

4. 怎麼操作

有 4 種方式,可以混著用:

🖱️ 滑鼠
拖右邊的搖桿圓圈、點按鈕、拉 LT/RT 扳機。
一次只能按一個 → 要同時按就開 🔒 鎖定模式,或用鍵盤。
⌨️ 鍵盤(最推薦)
可以同時按好幾個鍵,一手開車一手射球。按鍵表在下面,右邊搖桿上方也可以展開看。
🎮 Xbox 手把
USB 或藍牙接上 → 在畫面上按一下手把任一顆鍵(瀏覽器規定)→ 第 1 支是駕駛手、第 2 支是操作手。每個搖桿右上角的選單可以換。
📱 手機 / 平板
手機連同一個 Wi-Fi(或連筆電的行動熱點),打開網頁最下面寫的網址。一次只能一個畫面控制,用手機時先關掉電腦上的。

5. 第一次開車(LEO)一步一步

  1. 右上角按 啟用。
  2. 按住 W 往前開,A D 轉彎。車子有重量,起步會加速、放開會滑一下。
  3. 按 ↓ 一下下把手臂放下(側面圖會看到手臂變平)。按太久會跳紅字「超過行程」—— 因為 LEO 的軟限位還沒開。
  4. 按住 Q 開去場中間的球海,球會一顆顆吸進來(左上角「車上」數字會增加)。
  5. 按 ↑ 一下下收手臂,開到 HUB 的斜前方大約 4 公尺(正前方被 TOWER 擋住)。
  6. 按 R 開飛輪 → 地上出現落點圈。用 A D 或 ← → 對準,前後移動直到圈變綠色。
  7. 停穩之後按住 F 連發 🎯。開車中射球會帶著車速飛歪(跟真的一樣)。
  8. 玩完按 空白鍵 停用,或直接關視窗(模擬器會跟著關)。

6. 跑別人的程式(不是 LEO)

  1. 起始畫面「開啟機器人專案資料夾」選他們的專案。
  2. 第一次開會自動跳出 ⚙️ 機構設定(之後可以從畫面上方打開)。
  3. 先關掉設定視窗 → 按啟用 → 動一動搖桿 → 再打開 ⚙️ 機構設定。
  4. 每一列選「數值來源」:右邊「目前數值」會跟著跳的就是選對了。
    • NetworkTables:程式裡 SmartDashboard.putNumber(...) 或 AdvantageKit 發的數字
    • 模擬硬體:程式裡的 SPARK MAX / Talon FX / PWM 馬達(模擬時會自己出現)
    • 用不到的機構選「沒有這個機構」
  5. 填倍率:出力是電壓的話填 0.0833(= 1/12);飛輪是 RPM 的話填 0.01667(= 1/60);方向相反就填負數。
  6. 按 💾 儲存 → 存成那個專案裡的 .robot-sim.json,下次打開自動套用,也可以 commit 給隊友。
⚠️ 目前只支援坦克式(左右輪)底盤;swerve 還沒做。

7. 常見問題

按搖桿機器人不動
  • 還沒按右上角「啟用」(最常見)
  • 上面「模擬器」燈沒亮 → 見下一題
  • 別的專案:⚙️ 機構設定還沒設,模擬器不知道哪個是輪子
顯示「另一個搖桿網頁正在控制模擬器」 模擬器一次只讓一個畫面控制。把其他開著的模擬器視窗、瀏覽器分頁、手機上的畫面關掉,這個畫面會自己接上。
開專案後跳「模擬器啟動失敗(程式可能編譯不過)」 你的程式有錯誤。視窗裡會列出錯誤訊息最後幾行;用 VS Code 打開同一個專案按 Build 看紅字,改好再開。
雙擊之後好像沒反應 第一次開要 10~15 秒(防毒掃描),等一下。還是沒有:看工作列有沒有 9427 的圖示,點它。
找不到 WPILib 模擬器要用 WPILib 附的 Java 來跑程式,先照第 1 節裝 WPILib 2026。
畫面很卡 切成「2D 俯視」;或筆電插電、關掉其他程式。有獨立顯卡的筆電,Windows 設定 → 顯示器 → 顯示卡 → 把模擬器設成「高效能」。
3D 畫面跟真的機器人長得不一樣 場地是 FRC 官方模型;機器人目前用官方 KitBot 加上砲台和手臂。之後會換成隊上的 CAD。

8. 更新

不用重新下載。軟體打開時會自己檢查新版 → 背景下載 → 跳出「新版本已經下載好了」:

  • 「現在重開更新」:馬上更新(幾秒鐘)
  • 「等一下」:繼續用,關掉軟體時自動裝好
